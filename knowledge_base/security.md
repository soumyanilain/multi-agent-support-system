# Security Issues

## Description

Use this procedure when a user reports a potential security concern involving their account, device, credentials, or company information.

Security issues should be handled carefully because they may require additional investigation rather than a normal technical support procedure.

## Symptoms

* User believes their account has been compromised.
* User cannot complete required identity verification.
* User reports suspicious login activity.
* User believes their password was exposed.
* User reports a suspicious message or link.
* User observes unexpected activity on their account.

## Troubleshooting Steps

1. Do not request or record the user's password.
2. Determine what security concern the user is reporting.
3. Record relevant information without collecting sensitive credentials.
4. If the user believes their password was exposed, direct them to the approved account security procedure.
5. If suspicious activity is reported, preserve the relevant information and follow the security escalation procedure.

## Resolution

Security-related issues should be handled according to the company's security procedures.

A normal password reset should only be performed after the user's identity has been successfully verified.

If identity verification cannot be completed, do not modify the account.

## Ticket Category

Security

## Escalation

Escalate to the Security team when:

* The user reports suspected account compromise.
* Suspicious login activity is reported.
* The user cannot complete identity verification.
* Sensitive information may have been exposed.
* A potential phishing or security incident is reported.

Do not attempt to resolve a suspected security incident using only the standard technical troubleshooting procedures.
