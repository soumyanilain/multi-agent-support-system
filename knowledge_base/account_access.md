# Account Access

## Description

Use this procedure when a user cannot access their company account. Common problems include forgotten passwords, locked accounts, and repeated failed login attempts.

## Symptoms

* User cannot log in.
* User receives an "account locked" message.
* User reports multiple failed login attempts.
* User is unsure whether their password is correct.

## Troubleshooting Steps

1. Ask the user what error message they receive.
2. Determine whether the account is locked or the user has forgotten their password.
3. If the user forgot their password, follow the Password Reset procedure.
4. If the account is locked because of repeated failed attempts, follow the Account Unlock procedure.
5. Verify that the user can successfully authenticate after the issue is resolved.

## Resolution

For a forgotten password, verify the user's identity and follow the approved password reset procedure.

For an account locked because of failed login attempts, verify the user's identity and unlock the account using the approved account management procedure.

## Ticket Category

Account Access

## Escalation

If the user's identity cannot be verified, do not modify the account. Escalate the issue to the Security team.

If the account becomes locked repeatedly after the password has been reset, escalate the issue for further investigation.
