# Software Issues

## Description

Use this procedure when a user is unable to install, launch, update, or properly use an approved software application.

## Symptoms

* Application will not start.
* Application crashes unexpectedly.
* User cannot install an approved application.
* Application reports an error during an update.
* Application behaves differently after an update.

## Troubleshooting Steps

1. Identify the application and version involved.
2. Record any error message displayed by the application.
3. Verify that the application is approved for use.
4. Restart the application.
5. Restart the computer if appropriate.
6. Check whether an update is available.
7. If installation fails, verify that the user has the required permissions.

## Resolution

For a software application that is not responding correctly, restart the application and verify that the latest approved version is installed.

If the application cannot be installed because the user does not have sufficient permissions, the request may require administrative assistance.

## Ticket Category

Software

## Escalation

Escalate the issue if:

* The application continues to fail after basic troubleshooting.
* Administrative permissions are required.
* The application may have a compatibility problem.
* The application is not on the approved software list.
