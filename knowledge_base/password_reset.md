# Password Reset

## When to Use

Use this procedure when a user cannot access their account
because they forgot their password.

## Required Verification

Before resetting a password, verify the user's identity
using the approved identity verification procedure.

## Resolution

After identity verification:

1. Reset the user's password.
2. Ask the user to create a new password.
3. Confirm that the user can successfully log in.

## Ticket Category

Account Access

## Escalation

If the user cannot be verified, do not reset the password.
Escalate the ticket to the Security team.
