# Email Issues

## Description

Use this procedure when a user reports problems sending, receiving, or synchronizing company email.

## Symptoms

* New messages are not appearing.
* User cannot send email.
* Email application repeatedly asks for credentials.
* Messages are delayed.
* Email is not synchronizing between the user's computer and the mail server.

## Troubleshooting Steps

1. Determine whether the problem affects sending, receiving, or both.
2. Check whether the user's internet connection is working.
3. Verify that the email application is connected to the company account.
4. Restart the email application.
5. If appropriate, restart the computer.
6. Check whether the issue occurs through the company's webmail interface.
7. Record any error messages displayed by the application.

## Resolution

For a temporary synchronization problem, restart the email application and verify that messages are synchronized.

If email works through webmail but not through the desktop application, the issue may be specific to the email client.

## Ticket Category

Email

## Escalation

Escalate the issue if:

* The user cannot access email through either the desktop application or webmail.
* Multiple users report the same email problem.
* The account repeatedly requests credentials.
* Messages remain unavailable after basic troubleshooting.
