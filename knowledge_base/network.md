# Network Connectivity

## Description

Use this procedure when a user cannot connect to the company network, Wi-Fi, or other network resources.

## Symptoms

* Wi-Fi will not connect.
* User cannot access internal websites.
* Network connection repeatedly disconnects.
* Computer reports that there is no internet connection.
* Other network resources cannot be reached.

## Troubleshooting Steps

1. Confirm that Wi-Fi or the appropriate network connection is enabled.
2. Check whether the problem affects only one website or all network resources.
3. Disconnect and reconnect to the network.
4. Restart the computer if appropriate.
5. Check whether other users or devices are experiencing the same problem.
6. If possible, verify that the computer has received a valid network address.

## Resolution

For a basic connectivity problem, reconnect the device to the network and verify that the user can access the required resources.

If the problem affects multiple users or devices, the issue may require investigation by the Network Support team.

## Ticket Category

Network

## Escalation

Escalate the issue if:

* Multiple users are experiencing the same connectivity problem.
* The user cannot reconnect after basic troubleshooting.
* Internal network resources remain unavailable.
* A network outage is suspected.
